# DPI-HT-01 — Vladislavs Grigorjevs

University accounting/finance submission dashboard based on `public/submission.json`.

## Run locally
1. Install Node.js 20+.
2. Open Terminal in this folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000

## Deploy
Upload this entire project to GitHub, then import the repository into Vercel. Vercel detects Next.js automatically.

The public JSON submission is available at:
`/submission.json`
